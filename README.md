# LogisticRegression_manually
- A Logistic Regression implementation built completely from scratch using NumPy without using scikit-learn.

### Features
- Logistic Regression from scratch
- Gradient Descent
- Sigmoid function
- Binary Classification
- Feature Standardizatio
- Log Loss calculation
- Probability prediction
- Confusion Matrix
- Accuracy
- Precision
- Recall
- F1 Score
- Specificity
- Loss Curve visualization

### Tech Stack
- Numpy
- Pandas
- Matplotlib
- Seaborn


### Working
- Standardizes the input features.
- Adds a bias column.
- Initializes weights with zeros.
- Uses the Sigmoid function to convert linear output into probabilities.
- Optimizes weights using Gradient Descent.
- Calculates Log Loss during training.
- Predicts class labels using a threshold of 0.5.
- Evaluation metrics to evaluate the model
